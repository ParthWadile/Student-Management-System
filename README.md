# Java Basics Project — Student Management System

A beginner-friendly console project built with core Java. It demonstrates:
- Variables and data types
- `Scanner` input
- `if/else` and `switch`
- Loops
- Methods
- Arrays
- Classes and objects
- Constructors and `this`
- Basic validation

## Requirements
- JDK 8 or newer
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal

## Run from the terminal
Open a terminal in this folder and run:

```bash
javac Main.java Student.java StudentManager.java
java Main
```

## How to use
Choose an option from the menu to add a student, view all students, search by ID, calculate an average, or exit. Data is kept in memory while the program runs; it is not saved to a file or database.

## Suggested practice
1. Add a menu option to update a student's marks.
2. Prevent duplicate student IDs.
3. Add a grade calculation method.
4. Save and load student data from a text file.
