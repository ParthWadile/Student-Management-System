# 🎓 Student Management System | Java Basics ☕

A beginner-friendly **Student Management System** built using Core Java. 🚀 This console-based application helps manage student records while practicing essential Java programming concepts.

---

## 📌 About the Project

The **Student Management System** is a simple Java console application designed to store and manage student information during program execution.

This project is created to strengthen the fundamentals of Java through practical implementation of variables, arrays, methods, constructors, classes, objects, loops, and conditional statements.

🎯 **Project Goal:** Learn Java basics by building a practical, real-world mini-project.

---

## ✨ Features

- ➕ **Add Student** – Add new student records.
- 📋 **View All Students** – Display all available student details.
- 🔍 **Search Student** – Find a student using their ID.
- 📊 **Calculate Average** – Calculate the average marks.
- 🔄 **Menu-Driven Program** – Navigate through different options.
- ✅ **Basic Validation** – Handle basic input validation.
- 🚪 **Exit Application** – Close the program safely.

## 🚀 How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ParthWadile/Student-Management-System.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Student-Management-System
```

### 3️⃣ Compile the Java Files

```bash
javac Main.java Student.java StudentManager.java
```

### 4️⃣ Run the Application

```bash
java Main
```

🎉 That's it! You can now interact with the Student Management System through the console.

---

## 🖥️ Application Workflow

1. 🚀 Start the application.
2. 📋 Select an option from the menu.
3. ➕ Add student details.
4. 👀 View all student records.
5. 🔍 Search for a student using their ID.
6. 📊 Calculate the average marks.
7. 🚪 Exit the application.

> 📝 **Note:** Student records are stored in memory while the program is running. The data is not permanently saved to a file or database.
